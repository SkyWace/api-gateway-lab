# Fiche protocole — modèle

| Rubrique | Contenu |
|---|---|
| **Objectif** | Ce qu'on cherche à vérifier |
| **Hypothèse** | Résultat attendu, *formulé avant le test*, par solution si besoin |
| **Environnement** | Machine hôte, versions (cf. `02-architecture.md`), limites CPU/RAM, profil compose |
| **Procédure** | Étapes reproductibles, commandes exactes |
| **Mesures** | Indicateurs, fichiers produits dans `results/`, nb de répétitions |
| **Résultat** | Tableau observé + écarts, incidents, limites de validité |
| **Décision** | Conséquence sur le choix et compromis identifiés |
